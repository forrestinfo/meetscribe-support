MeetScribe

MeetScribe is a local-first macOS app for multilingual meeting transcription, bilingual live captions, speaker identification, translation, and structured meeting notes.

Quick Help

  • Grant microphone permission to capture your own voice.
  • Grant System Audio Recording Only permission to capture meeting audio from macOS apps. MeetScribe never records the screen.
  • Choose a visible meeting folder with the standard macOS folder-selection dialog before recording.
  • Complete the first-run tests for speech recognition, translation, and meeting-summary providers.
  • Use local providers by default, or explicitly configure cloud providers in Settings.

Common Questions

  • Why can’t I hear remote participants in transcripts? Remote meeting audio is treated as system audio on macOS, so System Audio Recording Only permission and system-audio capture must be enabled.
  • Does MeetScribe upload my data by default? No. MeetScribe is local-first. Cloud or local network providers must be chosen explicitly by the user.
  • Why is system translation unavailable? Some language pairs rely on Apple system translation packages or a user-configured translation provider.
  • Why did a provider test pass but a later request fail? Check that the model name, API key, service URL, quota, and network access are still valid. MeetScribe shows the provider response without silently replacing it with mock output.
  • Where are exported files saved? Choose a destination during export or set a default export folder in Settings. Exported transcript and summary filenames include a timestamp and can be revealed in Finder.
  • Can I rename detected speakers? Yes. Renaming a detected speaker updates every matching segment in the meeting transcript.
