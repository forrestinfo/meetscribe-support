MeetScribe Privacy Policy

MeetScribe is designed as a local-first macOS app for meeting transcription, translation, captions, and notes.

What MeetScribe Accesses

  • Microphone: to capture the local speaker.
  • System Audio Recording Only: when the user starts a meeting, MeetScribe uses Apple's Core Audio Process Tap to receive audio samples played by meeting apps. MeetScribe has no feature that records the screen and does not collect pixels, screenshots, video, window titles, window contents, or screen metadata.
  • Calendar: to read nearby event titles and suggest a meeting name. MeetScribe does not create, modify, or delete calendar events.
  • User-selected files and folders: before a recording can start, the user chooses a visible save folder with the standard macOS folder-selection dialog. Meeting audio, transcripts, and notes are never saved as user documents inside MeetScribe's hidden App Sandbox container.

Default Data Handling

  • Audio, transcripts, translations, and notes are stored locally in the user-selected visible folder.
  • MeetScribe does not upload meeting audio or transcript content by default.
  • API keys are stored in the macOS Keychain when the user configures optional third-party providers.
  • Users control where exported records and summaries are saved.

Optional Third-Party Providers

MeetScribe can connect to user-configured local or cloud providers for speech recognition, translation, or summary generation. Audio samples are sent only to a speech provider the user explicitly configures and selects. Transcript text is sent only to a translation or summary provider the user explicitly configures and selects. Each provider processes data under its own privacy policy and terms. MeetScribe's developer does not receive a copy.

Analytics and Tracking

  • No third-party advertising SDKs are included.
  • No tracking is performed by default.
  • No personal meeting data is collected for analytics by default.

Retention and Deletion

MeetScribe does not operate a developer-controlled cloud database for meeting content. Local audio, transcripts, translations, summaries, and exports remain until the user deletes them from the selected folder through Finder. Credentials for optional providers can be removed from MeetScribe settings and the macOS Keychain. Third-party provider retention is governed by the provider selected by the user.

Data Sharing

MeetScribe does not sell personal data. Meeting content is shared only with a provider explicitly configured by the user when needed to fulfill a requested speech-recognition, translation, or summary operation.
